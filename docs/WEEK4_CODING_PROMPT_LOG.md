2. **Marketing content system**

4. **Copy and text export**  
   Add working browser-native Copy and `.txt` Export controls for landing copy, every social post, each video script, and the complete campaign calendar. Include clear feedback, filenames, accessible controls, and responsive styling without paid APIs.

5. **Private saved marketing assets**  
   Review the existing Supabase integration and add authenticated, owner-scoped storage for landing copy, individual posts and scripts, and the calendar. Reuse the public client configuration, keep RLS enabled, avoid service-role keys, provide SQL setup instructions, and preserve the A/B tester and Copy/Export features.
