# CakeMatch AI

CakeMatch AI is a simple web experience for planning the perfect cake for any celebration. It will eventually help people choose a cake size, flavor, and design.

## Week 0 objective

Create the first visual version of CakeMatch AI. Week 0 focuses on the product idea, the page structure, and the visual direction before recommendation features are built.

## Current features

- Homepage with the CakeMatch AI concept
- Spanish navigation and content
- Hero section with an inactive recommendation button
- Preview of planned product features
- Documentation placeholder page
- Responsive layout for mobile screens

## Future features

- Personalized cake recommendations
- Designs for different occasions
- Estimated budgets
- Saved favorite cakes

## Tech stack

- Next.js 16 with the App Router
- React 19
- TypeScript
- Tailwind CSS
- ESLint

## Install dependencies

Install Node.js, then run:

```bash
npm install
```

## Run locally

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in a browser.

## Week 0 scope cuts

The following work is intentionally outside the Week 0 scope:

- No recommendation engine or AI API
- No user accounts or authentication
- No payments or checkout
- No database or saved user data
- No production ordering flow
